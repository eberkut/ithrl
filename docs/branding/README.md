# ithrl branding

The spear mark connects ithrl's name to Ithuriel in *Paradise Lost*. Two staggered context planes
open around a central diamond. The long diagonal and the lower-left plane's continuous taper are
intentional parts of the silhouette.

## Assets and placement

| Location | Contents |
| --- | --- |
| `source/` | Canonical geometry, generator, original font and its license |
| `overrides/` | MkDocs Shadcn sharing metadata |
| This directory | Light/dark logos, header icon, favicon, README fallback, site sharing card and CSS |
| [`social-preview.png`](social-preview.png) | GitHub sharing card; uploaded separately |

Use `light` artwork on light backgrounds and `dark` artwork on dark backgrounds. The SVGs have
outlined lettering and no font downloads, raster images or external resources. Each asset is kept
only in the location where it is used.

Use the horizontal logo around 320 px wide in the README and 280 px wide on the documentation
homepage. Use the standalone mark at 32 px in the header beside the site title. At 16 px the
silhouette carries the identity; use 32 px or larger when the central diamond and channels need
to remain distinguishable.

Preserve aspect ratio, the transparent channels and the full spear tips. Do not independently
stretch either axis, rotate the mark, or add gradients, outlines or shadows. The six emblem shapes
and five letter paths have descriptive editable IDs. Corresponding plane edges have an angle near
50 degrees; the upper point, diamond center and lower tip share the main axis. The wordmark's
vertical placement follows the context body rather than the spear's extreme tips.

## Colors and lettering

| Use | Color |
| --- | --- |
| Light-background artwork | Graphite `#202427` |
| Light-background accent | Teal `#00A58F` |
| Dark-background artwork | White `#FFFFFF` |
| Dark-background accent | Teal `#24CDB5` |

The wordmark uses Geist Bold, with its circular-dot `i` (`ss08`) and straight `l` (`ss03`),
converted to paths with optically adjusted spacing. Normal site typography remains owned by the
theme.

## Rebuild and check

From the repository root, install the locked branding tools:

```bash
uv sync --locked --group branding
```

Regenerate the logos, icons and sharing cards directly in their final locations:

```bash
uv run --locked --group branding python docs/branding/source/build_assets.py
```

Check generated bytes without changing files:

```bash
uv run --locked --group branding python docs/branding/source/build_assets.py --check
```

FontTools outlines the bundled font; resvg renders the SVGs without loading system fonts. Both are
pinned in the optional `branding` dependency group. Generation performs no network operations.
Edit geometry and placement in `source/geometry.json`, then regenerate; do not edit generated files.
The CSS and template override are maintained directly. Documentation tests check the published
asset boundary; use `--check` when editing the artwork or updating its tools.

## Repository, site and sharing integration

The README uses absolute image URLs so it also works as the PyPI description. GitHub selects the
light or dark SVG through `<picture>`. PyPI strips the `<source>` elements and uses the PNG
fallback, which has a white background to preserve legibility independently of the surrounding page.

MkDocs uses `theme.icon` for the inline 32 px mark. The site's `.dark` class controls its colors and
the homepage logo, including when the user selects a mode different from the operating system.
The SVG favicon follows the browser's `prefers-color-scheme`. The site and source distribution
include only the seven files explicitly allowlisted in `mkdocs.yml` and `pyproject.toml`: the two
logos, header icon, favicon, README fallback, site sharing card and CSS. This guide, `source/`,
`overrides/` and `social-preview.png` stay out of GitHub Pages, source distributions and installed
packages.

The 1200 × 630 site card is connected through the theme's extra-head template. For the repository,
upload `docs/branding/social-preview.png` under **Settings → Social preview** after merging the
assets. It is 1280 × 640 with a solid background, following
[GitHub's sharing-image guidance](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/customizing-your-repositorys-social-media-preview).
Committing an image alone does not change that setting.
